## 重点：圆 → 鬃毛轮廓 → 实心狮（f110–f180 逐帧）

证据：`zoom_a_l/d.png`（f114–f137 每帧）、`zoom_b_l/d.png`（f138–f184 隔帧）、`seam_l/d.png`（f131–f136 右下原尺寸）、`front_l/d.png`（f140–f145 原尺寸）、`keyframes_l.png`（f131/132/133/142/148/150）。

### 做对了的

1. **交接帧零跳变。** f112–f121 环的 bbox 恒为 x1011–1559、y476–1024。f119→f120 墨迹面积 −0.09%，线宽 5.85→5.85 px，亮暗两版一致（`handoff35.txt`）。看不出 `.ring` → `.outline` 换了元素。
2. **没有错位叠形。** 极点 = 鼻心 = ▶ 中心，变形全程只有一条闭合线。v3.4 的"两个形状错位叠加"和下巴下的灰弧都已消失。
3. **轮廓精度。** 720 点径向采样与真实鬃毛外缘最大偏差 0.27 单位、平均 0.11 单位（2K 下 <1 px），轮廓对鼻心是星形，0 处回折（`maneck35.txt`）。肉眼看不到多边形感。
4. **五官不碎。** 五官 2.40 s 起整体淡入，没有一帧出现被波前切开的眉毛或嘴。f143 面部空洞完整打开，f144 五官才开始出现，时机正好。
5. **明暗对称。** 暗版上的问题与亮版完全相同，没有单边问题。

### 问题（按严重度）

- **A. f132 线宽一帧突跳 ×1.65。**
  - 实测环带平均厚度：f131 4.15 px → **f132 6.85 px** → f133 7.17 → f134 8.26（`width35.txt`）。
  - 原因：`drive()` 在 F0（2.20 s）把遮罩描边从 0 直接设成 `2·w0`（半宽 = w0），而 outline 的半宽只有 w0/2。凡是轮廓仍在鬃毛内部的地方，可见的线一下子变成两倍粗。
  - 后果：加粗不是"慢慢长出来"，而是"先跳一下、停 1 帧、再加速"。
- **B. f132–f135 右下（约 20°–70°，即 4 点到 5 点方向）出现发丝白缝，读作双线。**
  - 每帧 724–1014 个"墨—亮—墨"夹心像素，夹心最深 α 差 1.00 / 0.98 / 0.84 / 0.50，到 f136 降为 0.20（`sliver35.txt`）。
  - 原因（`maneck35.txt` 已用数据核对）：此处鬃毛半径最小（71.7 u，在 51°），而 2.20 s 时环半径 rc 是 82.5 u。轮廓还在鬃毛外缘**之外** (1−m)(rc−R) = +1.73 u，大于 outline 半宽 1.14 u。于是 outline 的内边和"遮罩 ∩ 鬃毛"的外边之间留出一条真实的缝；随着 m→1，缝收窄成抗锯齿发丝线。
- **C. f142 波前锯齿（1 帧）。** 加粗带的内边是星形多边形的等距线，它切过面部空洞时，在眉角、两颊、下巴处留下 6–8 个 2–6 px 的台阶或小齿（`front_l.png` 第 3 格）。f141 和 f143 是干净的。
- **D. f137–f141 中间态偏"齿轮/徽章"。** 加粗带内边是多边形等距线，凸角在内侧是尖角。5 帧里读作一个粗壮的九角环，比最终鬃毛更"机械"。可以接受，属于风格取舍。
- **E. 五官灰度阶段。** feat 不透明度在 f147–f152 为 .19 / .38 / .57 / .71 / .81 / .88。亮版上眉和嘴有 6 帧是中灰色，像占位符。不算廉价，但比墨色直接出现弱一档。
- **F. 变形前段集中。** emph 让 m 在 f121–f126（100 ms）走完 0→0.55，峰值 0.144/帧（f124）。同时镜头在拉远，屏幕上读作"角一下子顶出来"。不突兀，但比后面舒缓的加粗"急"。

### 声音

- 滑音音高用的就是 `morph35.bez(.4,0,.2,1)`，与画面形变同一函数、同一 MD=.6 s，构造上零滞后。v3.4 P3-1 已修好。
- thump：sub-150 Hz −6 dB 起音在 2.335 s，峰值 2.343 s（WAV 与 MP4 一致）。画面上加粗速度峰值在 f138–f139（2.30–2.32 s），面部空洞打开在 f143（2.383 s）。thump 落在两者之间，"砰"与"填满"同步。
- 变形最急的 f122–f125（2.03–2.08 s）没有对应的声音细节，swell 只是平滑上扬。可选：加一个很轻的高频 shimmer 去承接"角顶出来"（见 P3-4）。

## P2

**P2-1　加粗起步的线宽突跳和右下双线（f132–f135，2.20–2.25 s）**

两处问题同一个根因：变形中的轮廓 ≠ 鬃毛外缘时，就用"遮罩 ∩ 鬃毛"去显示加粗。修改都在 `template35.html` 的 `drive()` 里（复制为 template36）：

1. **遮罩起始宽度与 outline 一致**（单独修这一步就能消除 ×1.65 突跳）：
   ```js
   TP.setAttribute('stroke-width', ms < F0 ? 0 : (w0 * (1 - f) + 220 * f).toFixed(3));
   ```
   即把 `2 * w0 * (1 - f)` 改成 `w0 * (1 - f)`。
2. **m 尚未到位时，被遮罩显示的内容用"轮廓自身的实心填充"代替鬃毛**，这样被显示内容的外缘就是轮廓中线，永远被 outline 盖住，不会出缝：
   - 在 `.reveal` 里加一条 `<path id="olFill" class="ink"/>`。
   - `m < .96` 时：`olFill` 的 d = 当前轮廓 d，隐藏鬃毛 path。
   - `m ≥ .96` 时（约 f139，此时 (1−m)(rc−R) ≤ 0.6 u，小于 outline 半宽 1.0 u）：切回鬃毛 path，隐藏 olFill。
   - 加粗带在 f139 前最多向内 15 u，还碰不到面部空洞，所以用轮廓填充代替鬃毛在视觉上完全等价。
3. **可选（替代第 2 步，改动更少）**：把加粗起点 F0 从 2.20 推迟到 2.30。这时 m=0.953，右下偏移约 0.5 u，小于 1.1 u，缝就消失了；同时 FD 改为 .62，让加粗结束仍在约 2.92 s；thump 改到 2.38，五官改到 2.44。代价是变形和加粗的重叠减少 0.1 s。
- 验收：
  - `width35.py` 相邻帧线宽比 ≤ 1.35；
  - `sliver35.py` 在 f126–f140 的夹心像素 < 50、最大 dip < 0.2。
- 预期收益：工艺 +0.4、节奏 +0.1，总分约 8.6。

## P3

**P3-1　f142 波前锯齿（1 帧）**
- 最省事的办法：让加粗带越过面部空洞边界的那段更快。把 THK 改为 `cubic(.4,0,.1,1)`，或者在 `maskW > 75 u`（约 f142）时直接把遮罩切成 `fill="#fff"` 的鬃毛外轮廓（因为此时带内边已贴近空洞，差量只是那几颗齿）。
- 用 `front_l.png` 同位置复查，f141–f143 都不应再有台阶。

**P3-2　五官淡入的灰度阶段缩短**
- `.feat` 改成 `fadeIn .14s cubic-bezier(.2,0,0,1) 2.40s`：中灰帧从 6 帧降到约 3 帧，且前快后稳，避免"灰色占位符"感。
- 可选：叠加 `transform: scale(.94)→1`，原点为鼻心 (131.5,147)。这样五官像"从鼻子散开"而不是"浮现"，与整条叙事更一致。

**P3-3　变形前段过急（f121–f126）**
- 变形缓动从 emph 换成 `cubic(.3,0,.1,1)`，或者保持 emph、把 HD 从 450 延长到 550 ms。目标是 m 的峰值速度 ≤ 0.10/帧（现为 0.144）。
- 注意：这会让 m 到位更晚，必须先做 P2-1 第 2 步（或者相应推迟 F0），否则双线问题会更长。

**P3-4　声音承接变形（可选）**
- 在 2.02–2.12 s 加一个极轻（约 −30 dB 相对 thump）的高频 air/shimmer，用 bez(.2,0,0,1) 包络，承接"圆角顶出"。
- 保持克制，不加也不扣分。

**P3-5　▶ 光学偏左（沿用 v3.4 P3-4，未处理）**
- 静态 `translate(-2.2 0)` 加在 `.ui` 内的 ring/ripple 外层。
